COLA DIREITO 013 — SITE

Como abrir:
1. Extraia a pasta completa do ZIP.
2. Abra index.html em um navegador moderno.
3. A navegação entre Início, Materiais, Ações e Participe funciona no próprio site.
4. Os botões de download baixam os arquivos incluídos na pasta.

Os materiais de download são os arquivos recebidos no ZIP enviado pelo usuário. O site foi preparado a partir das capturas de referência do Figma, adaptado para celular e desktop.
